# 014 — QA and release hardening

## Goal

Prepare the MVP for real pilot use.

## Read first

- `docs/TESTING.md`
- `docs/SECURITY_PRIVACY.md`
- `docs/ROADMAP.md`

## Deliverables

- Critical E2E flows complete.
- Accessibility pass on primary screens.
- Mobile responsive review.
- Error/empty/loading/offline states reviewed.
- Production error boundaries.
- Vercel deployment documentation.
- Supabase environment documentation.
- README updated with development/setup/release instructions.
- Known limitations documented.

## Acceptance criteria

- Full quality suite passes.
- Production build succeeds.
- No secrets committed.
- English/Spanish primary flows complete.
- Pilot user can install app and complete the full daily loop.

## Tests / verification

Run lint, typecheck, unit, component, E2E and build. Report any skipped checks.

## Out of scope

- No AI.
- No video.
- No extra social/coach features.

## Completion rule

Do not begin another spec. Report implementation, tests, validation commands and deviations.
