# Product specification

## Product name

**Hoopnote**

## Product statement

Hoopnote helps basketball players improve intentionally by turning each practice or game into a small learning loop:

**focus → play → reflect → learn → adapt**

The product is not a virtual coach. It is a personal basketball journal and attention system.

## Core user promise

> Know what to focus on today, record what happened, and use that information to make tomorrow's focus better.

## Initial target user

- Basketball player aged 16+.
- Any gender.
- Developmental, competitive, college or similar structured environment.
- Has access to real coaches/trainers.
- Wants to improve tactical understanding, fundamentals and habits.
- May have a physical limitation or injury context, but Hoopnote never replaces medical professionals.

## Core concepts

### Daily focus

One primary actionable basketball cue for the day.

A daily focus should:
- be specific;
- be observable during play;
- be short enough to remember on court;
- relate to the user's goals and recent observations;
- avoid excessive repetition.

### Session

A practice, game, video/learning session or recovery day.

### Reflection

A 30–90 second post-session input capturing:
- how the focus went;
- what happened;
- coach feedback;
- something to remember.

### Player model

A structured representation of:
- profile;
- goals;
- self-assessment;
- observed strengths;
- recurring difficulties;
- recent focus history;
- skill trends.

The player model is not a scientific performance score.

## Primary navigation

1. Today
2. Game
3. Journal
4. Progress
5. Profile

The basketball taxonomy is content organization, not the main mental model of the app.

## MVP goals

A registered user can:
- create an account by email;
- complete onboarding;
- choose English or Spanish;
- work offline after initial load;
- receive a daily focus;
- record pre-session check-in;
- record a session and reflection;
- browse curated basketball guidance;
- inspect journal history;
- see simple progress trends;
- receive subsequent focuses influenced by historical data;
- sync data to Supabase.

## Out of scope for MVP

- AI interpretation of free text.
- Automatic video analysis.
- Video upload and clip library.
- Training load prescription.
- Rehab progression.
- Nutrition prescription.
- Medical diagnosis.
- Public profiles.
- Social features.
- Leaderboards.
- Coach dashboard.
- Advanced game statistics.

## Product principles

### 1. One useful thing beats ten generic things
The default daily experience should be small.

### 2. Reflection must be fast
Do not create a diary that feels like homework.

### 3. Progress is qualitative as well as quantitative
Avoid reducing a player's development to points, streaks or arbitrary scores.

### 4. Rest is not failure
No punitive streak mechanics.

### 5. Basketball content is curated
The application does not improvise technical guidance.

### 6. Safe boundaries
Physical-context information can influence wording and warnings, but Hoopnote never decides whether a user should train through pain or progress rehabilitation.

## Success indicators

- onboarding completion;
- daily focus viewed before sessions;
- reflection completion rate;
- 1-week and 4-week retained usage;
- weekly review usage;
- user-rated relevance of recommendations.

## Product tone

Energetic, concise, supportive and basketball-literate.
Avoid infantilizing language and generic motivational clichés.
