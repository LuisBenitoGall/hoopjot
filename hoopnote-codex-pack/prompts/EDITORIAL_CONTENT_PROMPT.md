# Prompt for basketball content work

Use this only when explicitly working on the Hoopnote curated basketball catalog.

```text
We are editing Hoopnote's curated basketball knowledge base.

Read:
- docs/PRODUCT.md
- docs/CONTENT_MODEL.md
- docs/I18N.md

Do not change application code unless explicitly requested.

For every proposed guideline:
- keep one observable behavior per guideline;
- provide English and Spanish;
- provide a short memorable court cue;
- identify category, subcategory, skills, level, positions and contexts;
- avoid universal claims where team schemes vary;
- do not prescribe rehab, medical treatment, training load or nutrition;
- avoid generic motivational content.

Return proposed content for human editorial review before adding it to production catalog files.
```
